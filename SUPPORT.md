# Support

## Where to ask

For reproducible defects, documentation corrections, and feature proposals, open an issue in the repository:

https://github.com/Brajesh31/Cake-Shop/issues

Include the route, steps to reproduce, expected and actual behavior, browser and operating system, and relevant console or network errors. Remove credentials and personal information from logs and screenshots.

For a security vulnerability, use the private process in SECURITY.md rather than a public issue.

## What this project supports

This repository is a React/Vite front-end example. Community support can help with the source, local setup, and documented routes. It does not currently provide or support live orders, payment processing, booking, customer accounts, inventory, message delivery, or a production bakery service.

The existing demo URL may be unavailable or may run a different revision. The maintainer cannot guarantee third-party deployment, CDN, font, or image host availability.

## Response expectations

The project is maintained by Brajesh Kumar (@brajesh31). There is no paid support agreement or guaranteed response time. Be respectful and follow CODE_OF_CONDUCT.md.
