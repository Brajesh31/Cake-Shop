# 🔒 Privacy notice for the project

## Application behavior
The current repository is a static front-end demonstration. Its source does not implement user accounts, contact submissions, order forms, checkout, payment handling, analytics, or a database for visitor records.

## Third-party requests
The page loads selected fonts, stylesheets, icons, and libraries from third-party CDNs. A browser request to those services may disclose ordinary connection metadata such as IP address and user-agent to the provider. Review the provider's current privacy terms and applicable legal requirements before production deployment.

## Hosting
The static hosting provider may process access logs and request metadata under its own terms. This repository does not control the provider's retention or processing.

## Future data collection
If the application begins collecting personal information, the project must add a clear privacy notice describing:
- What information is collected.
- Why it is needed and the applicable lawful basis.
- Which service providers receive it.
- How long it is retained.
- How a person can request access, correction, or deletion where applicable.
- How information is protected.

Do not collect customer or payment information until the service architecture, security controls, retention rules, and privacy documentation have been reviewed.

This project-level notice is not legal advice and does not replace the deployed service's own privacy policy.
