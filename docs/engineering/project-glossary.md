# 📖 Project glossary

| Term | Meaning in this repository |
| --- | --- |
| SPA | Single-page application; React Router changes the browser route without a full page reload |
| Vite | Development server and production bundler used by this project |
| Route | Browser path rendered by React Router |
| Layout | Shared header, main content region, and footer |
| Section | Reusable page-level content component |
| Public asset | A file in public/ served from the site root |
| CDN | External content delivery network used for styles, icons, or fonts |
| Static build | Generated dist files served by a static host |
| History fallback | Host rule returning index.html for client-side routes |
| Placeholder control | A visual element that does not yet perform its implied action |
| Commerce flow | Product selection, cart, checkout, order creation, payment, and fulfillment; not implemented in this version |
