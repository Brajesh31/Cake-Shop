# 🖼️ Visual assets and content

## Repository asset location

Current local images are stored in public/img and are available to the browser from root-based paths such as /img/logo.png.

## Asset workflow

1. Use images the project owner has permission to publish.
2. Prefer optimized WebP or AVIF for large photographic images where supported by the workflow.
3. Keep source image dimensions appropriate for the display context.
4. Provide meaningful alt text for informative images.
5. Use empty alt text for decorative imagery.
6. Avoid embedding text in images where live HTML text is practical.
7. Remove unused or duplicate assets after confirming they are not referenced.
8. Check file size and mobile loading impact before adding large media.

## Naming convention

Use lowercase descriptive names with hyphens, for example:
- chocolate-truffle-cake.webp
- bakery-interior.jpg
- seasonal-menu-banner.webp

Avoid generic names such as image-final-final2.jpg.

## Rights and attribution

The presence of an image in this repository does not prove that it is licensed for commercial reuse. Confirm ownership, license terms, model/property releases where applicable, and any attribution requirements before publishing.
